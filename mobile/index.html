How to use PrintPix Rush ID

Starting a job

When the app opens, choose New Job for a blank workspace, or Open Job to pick up one you saved before. Once inside, the Create New Job button in the header (top-right) clears everything for a fresh customer — it'll offer to save first if anything's unsaved.

1. Page Setup

Pick the paper you'll print on — standard sizes (2R–8R, A4, Letter, Legal) or Custom size (enter your own width/height in inches). Set Portrait or Landscape.

2. Upload & Edit

  • Upload a photo, then drag it and use the corner handles to reposition/resize — that framing is what gets cropped into every copy.
  • Remove background cuts out the subject (first use downloads a small AI model — needs internet once), then pick a background color, image, or leave it transparent.
  • Auto Enhance auto-adjusts levels, color, and sharpness (plain image processing, no AI, instant). Eraser brushes small areas to transparent — a dashed circle on the canvas shows the brush's actual size as you move the pointer, so it's easy to see what will be erased.
  • Under Command Options, pick Male/Female and click Add Formal Attire to have AI generate the person actually wearing formal attire — this sends the photo to whichever AI provider you've added and tested under AI Providers (the icon button, top-right of the header); add a free API key there first if nothing's configured yet. It tries your working providers automatically (free ones first) and replaces the photo with the result — needs internet every time, not just on first use.
  • Undo/Redo (Ctrl+Z / Ctrl+Y) step back and forth through your edits. The Delete photo button clears the current photo back to the empty drop-zone.
  • Workspace zoom only zooms your view (like Photoshop) — it doesn't change the photo's actual size or crop.

3. ID Sizing

Pick a size (or Custom W×H) and quantity, then Add to sheet. Repeat to mix sizes on one sheet (e.g. 4× 2×2 and 2× 1×1 together) — nothing shows in Live Preview until you Add. Each row of photos is centered on the sheet automatically as you add sizes, no separate step needed. Turn on Name tag to print a name (and pick its color) under each photo.

4. Preview & Print

Set the sheet margin, toggle the dashed cutting guide, and turn on Tight packing to fit more copies with no gap (cut carefully if so). Print and Export PDF both open the same Print Preview first — check it looks right, then choose either action from there.

5. Save Job

Give the job a label and click Save current job — in Chrome/Edge this opens a native Save dialog (filename defaults to the label, editable) so you choose exactly where the file goes; other browsers download it instead. Move that file via USB to open it with this app on another computer and it comes back exactly as it was, using Import job .json there (or "Open Job" at startup).

Each saved job also stays in the list below. Its Save button overwrites that same job with whatever is currently on screen (it asks to confirm first, since it replaces the previous file/entry) — handy for updating a job after reopening and editing it further. Delete only removes it from this list, not any file already saved to disk.

Good to know

  • Editing, arranging, Auto Enhance, and PDF export all work fully offline. "Remove background" needs internet only the first time it's used (its AI model then stays cached in the browser) — Add Formal Attire needs internet every time, since it calls a real AI provider over the network for each generation.
  • Saved jobs live only in this browser, on this computer — export a job as .json before switching devices or clearing browser data, or it'll be gone for good.
  • Live Preview only fills one physical sheet — if a size's quantity doesn't all fit, the extra copies just aren't shown (no multi-sheet pagination yet).
